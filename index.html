Shorts Agent

Shorts Agent is a personal automation tool that researches video ideas, produces short vertical videos (YouTube Shorts) and uploads them to its operator's own YouTube channel on a daily schedule.

What it does

  • Collects topic ideas from public trend sources and uses Google's Gemini API to score them and write a short script.
  • Builds each video from free stock footage, a synthetic voice-over and on-screen captions.
  • Uploads the finished video to the operator's own YouTube channel. Uploads start out private, so the operator can review them before anything is made public.
  • Reads the channel's own YouTube Analytics to learn which videos perform best, and adds each video to a playlist, with a subtitle track and a first comment, on the operator's own channel.

Who uses it

Shorts Agent is not a public service and has no sign-up. It runs only for the person who operates it, with that person's own Google account, and it only works with that person's own YouTube channel.

How it uses YouTube and Google data

When the operator connects the app, Google asks for permission to upload videos, read channel and analytics data, and manage playlists, captions and comments on the operator's own channel. These permissions are used only for the features described above. Details, including how access can be revoked at any time, are in the Privacy Policy.

Contact

For questions or requests about data (for example, to have the text of a public comment you wrote on one of the operator's videos deleted), please open an issue on GitHub.

Shorts Agent uses YouTube API Services. The operator is bound by the YouTube Terms of Service; see also the Google Privacy Policy.
