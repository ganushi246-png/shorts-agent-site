Privacy Policy

Shorts Agent · Last updated: 14 October 2026

In short: Shorts Agent only touches the YouTube channel of the person who runs it. It does not sell data, show ads or track visitors, and it shares Google user data with no one except Google's own Gemini API, as explained below.

1. Who operates Shorts Agent

Shorts Agent ("the app") is a personal, non-commercial tool operated by the owner of the GitHub account ganushi246-png ("the operator"). It is used only by the operator, on the operator's own YouTube channel. It has no user accounts, no advertising and no tracking.

This website is a static page hosted on GitHub Pages. It has no forms, cookies or analytics of its own; GitHub may process technical data about visitors under its own privacy statement.

2. What data the app accesses

The app can reach only data in the Google account the operator connects, and only through the permissions (OAuth scopes) the operator approves on Google's consent screen:

  • https://www.googleapis.com/auth/youtube.upload – upload videos to the operator's channel and set their title, description, tags, thumbnail and visibility.
  • https://www.googleapis.com/auth/youtube.readonly – read information about the operator's channel and videos (for example upload and processing status, public view counts and playlists), and search public YouTube videos to see how many similar Shorts already exist and how they perform (public counts only).
  • https://www.googleapis.com/auth/yt-analytics.readonly – read YouTube Analytics reports for the operator's own channel (views, engaged views, watch time, average view duration, likes, comments, shares and subscriber changes per video).
  • https://www.googleapis.com/auth/youtube.force-ssl – manage items on the operator's own channel: create playlists and add videos to them, upload subtitle (caption) tracks, post a comment from the operator's channel on the operator's own videos, and read public comments on the operator's own videos to find questions viewers ask.

The app does not request access to Gmail, Google Drive, contacts, calendar, location or any other Google account data.

3. How the data is used

Data is used only to run the features the operator sees: producing and uploading videos on a schedule, adding them to playlists with subtitles and a first comment, producing a weekly performance report, and choosing better topics and opening lines based on what has worked on the operator's channel. It is not used for advertising, is not sold, and is not used to build profiles of people. The operator does not use it to develop or train AI models.

4. Who the data is shared with

The app does not sell or rent data and does not share Google user data with anyone, with these exceptions:

  • Google's Gemini API. To write scripts, the app sends text prompts to the Gemini API. A prompt can include a short summary of how the operator's own videos performed (for example which topic categories and opening lines held viewers best) and the text of questions that viewers wrote in public comments on the operator's videos, without the commenter's name or channel ID. Google processes this content under the Gemini API terms.
  • GitHub. The app runs on GitHub Actions and keeps its working files in the operator's private GitHub repository (see section 5). GitHub processes that data as the host, under its own terms.
  • Legal reasons. Data may be disclosed if the law requires it or to protect rights and safety.

Other services the app uses, such as a stock-footage provider, receive only generic topic keywords, never Google account data.

5. Storage, security and retention

  • Credentials. The OAuth credentials that let the app act on the operator's channel are stored only as encrypted secrets in the operator's private GitHub repository. They are read only while a scheduled job runs, are never printed to logs and are never committed to the repository.
  • Working data. An upload log, a weekly performance report, the text of selected viewer questions (without commenter names) and similar files are kept in the same private repository. Only the operator can open it.
  • Retention. Data is kept for as long as the operator uses the app and is deleted when the operator deletes the files or the repository. Temporary video previews produced by a job are removed automatically by GitHub after 7 days.

6. Your choices

  • Revoke access. The operator can withdraw the app's access at any time in the Google Account under Security, Third-party apps and services (myaccount.google.com/permissions). After that the app can no longer read or change anything on the channel, and the operator deletes the stored channel data and credentials promptly, and in any case within 7 days.
  • Delete data. The operator can delete the stored credentials and files from the repository at any time.
  • Commenters. If you commented on one of the operator's videos and want the text of your comment removed from the app's stored files, use the contact link below and it will be deleted.

7. Google API Services User Data Policy

Shorts Agent's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

8. YouTube API Services

Shorts Agent uses YouTube API Services. By connecting a YouTube channel to the app, the operator agrees to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

9. Children

Shorts Agent is not directed at children and does not knowingly collect personal information from anyone under 13.

10. Changes

If this policy changes, the new version will be posted on this page with a new date.

11. Contact

Questions or requests about this policy or about data held by the app: open an issue on GitHub. Issues are public, so please do not include sensitive personal details.
